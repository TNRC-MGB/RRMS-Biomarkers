# scDRS MS-GWAS disease-relevance scores per cell

This directory holds the scDRS analysis: the MAGMA and scDRS
command-line steps and the Python covariate step. It produces `MS.score.gz`,
the per-cell MS-GWAS disease-relevance score that `R/figure2.R` (panels e-g) and
`R/preprocessing_bcells.R` read back into the Seurat objects.

Note two small R scripts are included here instead of `R/`: 
`01_prepare_inputs.R` and `03_magma_to_zscores.R`.

## Pipeline

```text
 MS GWAS summary statistics (MS.final.txt)
        |
        |  01_prepare_inputs.R           SNP / P / N  ->  MS.final.magma.tsv
        v
 02_magma.sh          --annotate  ->  MS_GWAS.genes.annot
                      gene analysis ->  MS_GWAS.genes.out / .genes.raw
        |
        |  03_magma_to_zscores.R         Entrez -> SYMBOL, keep max |Z|
        v
 MS_magma_symbol_zscore.tsv
        |
        |  04_munge_gs.sh                scdrs munge-gs, top 1000 genes
        v
 MS.gs   <- included in this directory (13 KB); lets you skip MAGMA entirely
        |
        |                        objects/pbmc_final.RDS --01_prepare_inputs.R--> ms_pbmc.h5ad
        |                                                                     |
        |                        05_make_covariates.py  ->  ms_pbmc.cov <-----+
        v                                                                     |
 06_compute_score.sh   scdrs compute-score  <---------------------------------+
        |
        v
 output/pbmc/MS.score.gz        per-cell norm_score, pval, zscore, nlog10_pval
 output/pbmc/MS.full_score.gz   + control scores (~1.3 GB)
```

The same workflow was run twice against the same `MS.gs`: once on the whole-PBMC
atlas (`ms_pbmc.h5ad` -> `output/pbmc/`) and once on the B-cell object
(`ms_bcells.h5ad` -> `output/bcells/`). Only the `--h5ad-file`, `--cov-file` and
`--out-folder` arguments differ.

## Running it

```bash
cd <repository root>
bash scdrs/02_magma.sh          # requires MAGMA v1.10 + the g1000_eur reference
Rscript scdrs/03_magma_to_zscores.R
bash scdrs/04_munge_gs.sh
python scdrs/05_make_covariates.py ms_pbmc.h5ad ms_pbmc.cov
bash scdrs/06_compute_score.sh ms_pbmc.h5ad ms_pbmc.cov output/pbmc
```

To skip MAGMA entirely, use the `MS.gs` in this directory and start at step 05.

### scDRS version

```text
-e git+https://github.com/martinjzhang/scDRS.git@7f8f8d5754e1e3057916cd3fbe720b96f90c1c1b#egg=scdrs
```

To reproduce the environment exactly:

```bash
python3.12 -m venv scdrs-env && source scdrs-env/bin/activate
pip install -r scdrs/requirements.txt
```

or to install just scDRS at the same commit:

```bash
pip install "git+https://github.com/martinjzhang/scDRS.git@7f8f8d5754e1e3057916cd3fbe720b96f90c1c1b"
```

Note `numpy==1.26.4` - the NumPy 1.x series. scDRS at this commit and the pinned
`numba`/`llvmlite` build are not NumPy 2 compatible, so a fresh
`pip install scdrs scanpy` today will resolve NumPy 2.x and will not reproduce
this environment.

### MS GWAS summary statistics

`MS.final.txt` holds the summary statistics from the International Multiple
Sclerosis Genetics Consortium multiple sclerosis genomic map:

> International Multiple Sclerosis Genetics Consortium. Multiple sclerosis
> genomic map implicates peripheral immune cells and microglia in
> susceptibility. *Science* **365**, eaav7188 (2019).
> https://doi.org/10.1126/science.aav7188 (PMID 31604244).

**Data availability statement**:

> MS GWAS summary statistics were generated by the International Multiple
> Sclerosis Genetics Consortium
> (https://doi.org/10.1126/science.aav7188) and were obtained from the
> consortium. They are not redistributed here; researchers may request them
> directly from the IMSGC (https://imsgc.net/). The derived gene set used for
> scDRS scoring is provided in the accompanying code repository
> (`scdrs/MS.gs`).

Only step 02 requires the summary statistics. Everything from step 04 onward
reproduces without them, because `MS.gs` (the gene set they were reduced to)
is included in this directory.

## Files in this directory

| File | Language | Step |
|---|---|---|
| `01_prepare_inputs.R` | R | Seurat -> h5ad; GWAS sumstats -> MAGMA p-value file |
| `02_magma.sh` | bash | MAGMA SNP->gene annotation and gene analysis |
| `03_magma_to_zscores.R` | R | MAGMA Entrez IDs -> gene symbols, scDRS z-score format |
| `04_munge_gs.sh` | bash | `scdrs munge-gs` -> `MS.gs` |
| `05_make_covariates.py` | Python | scanpy QC metrics -> scDRS covariate file |
| `06_compute_score.sh` | bash | `scdrs compute-score` -> `MS.score.gz` |
| `MS.gs` | data | the MS gene set actually used (top 1000 genes, z-score weighted) |
| `record_environment.sh` | bash | capture the Python environment -> `requirements.txt` |
| `requirements.txt` | data | the exact Python environment that produced `MS.score.gz` |
