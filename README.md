## Overview

This repository supports King et al., an observational study of longitudinal
blood samples from patients with relapsing-remitting multiple sclerosis, that 
builds a time-resolved atlas of the immune perturbations surrounding relapse. 

The analysis identifies a reproducible pre-relapse signature in monocytes and B
cells, emerging up to three months before clinical onset, that is enriched for
host genes responsive to Epstein-Barr virus lytic reactivation factors. It then
tests whether the affected populations are enriched for MS-GWAS heritability
(`scDRS`) and whether the pre-relapse transcriptional modules overlap
EBNA2-bound regulatory elements.

The cohort is 135 donors and 240 PBMC samples. Donors contribute to more than
one condition, so the per-condition counts in Supplementary Table S1 overlap:
69 pre-relapse, 44 relapse, 99 remission and 21 healthy control. Per-assay
sample tables are Supplementary Tables S1 to S9.

## Repository layout

```text
R/                           figure and analysis scripts, one file per figure
bulk/                        CD19+ bulk RNA-seq: Salmon quantification
scdrs/                       MAGMA and scDRS pipeline
data/                        small inputs
objects/                     local pipeline intermediates, not distributed
zenodo/                      large inputs from the Zenodo deposit
zenodo/bulk/counts/          Salmon per-sample quantifications
zenodo/scrna/counts/         Cell Ranger filtered feature-barcode matrices
zenodo/scrna/demux/          Vireo donor assignments, donor_ids.tsv per pool
Supplementary Information/   Supplementary Tables S1 to S9
Intermediate/                rendered panels, not distributed
```

Additional datasets and objects are grouped as follows:
`data/` is included here, `zenodo/` can be downloaded from the linked Zenodo, 
and`objects/` is regenerated by running the pipeline.

Only `donor_ids.tsv`, the final per-cell donor assignment, is deposited for each
pool. The Vireo intermediates it was derived from (the per-donor VCFs, the
cellSNP allele-count matrices and the assignment probability tables) carry
individually identifying genotypes and fall under the controlled-access

The MS GWAS summary statistics are third-party and are not redistributed here;
see [`scdrs/README.md`](scdrs/README.md) for how to obtain them from the
International Multiple Sclerosis Genetics Consortium.

Sample tables in `Supplementary Information/` depend on de-identified
`Sample_ID` and `Donor_ID`. Medical record numbers, draw dates and clinical
dates are not distributed, and no crosswalk to them is included.

## Running the pipeline

1. **Bulk RNA-seq** - [`bulk/README.md`](bulk/README.md). Builds a decoy-aware
   Salmon index against `refdata-gex-GRCh38-2020-A`, quantifies 130 CD19+
   libraries, and imports them to a TMM-normalized `DGEList`.
2. **scRNA-seq preprocessing** - `R/preprocessing_pbmc.R` then
   `R/preprocessing_bcells.R`. Writes `objects/pbmc_final.RDS` (about 5.5 GB)
   and the B-cell object.
3. **scDist** - `R/scrna_pbmc_scdist.R` writes the five whole-PBMC fits to
   `zenodo/scdist/`; `R/preprocessing_bcells.R` writes the B-cell fits.
4. **scDRS** - [`scdrs/README.md`](scdrs/README.md). MAGMA gene analysis on the
   MS GWAS, then per-cell disease-relevance scores.
5. **Figures** - the scripts in [`R/README.md`](R/README.md), each of which
   loads the objects above and renders to `Intermediate/`.

Please note, every script that draws on the random number generator sets a seed.
Several steps are still sensitive to package versions.
